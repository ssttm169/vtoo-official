Directory

Step 1.Set input and ouput​

Select the image directory you want to process and the output directory.

Step 2.Setting​

Set recursive subdirectories, image formats, watermarks, scaling, output formats, etc.

Step 3.Process​

Click the "Do it" button to batch process the images.

Step 4.Done​

You can check the number of images processed and the amount of space saved.
